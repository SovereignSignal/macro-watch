# macro.watch

Public macro intelligence site — a Sovereign Signal system. Presents the sovs-macro
pipeline's output: daily/weekend briefs, the living theme map with longitudinal
history, the self-grading accountability scoreboard, and the forward-event catalyst
board. Data arrives push-only from the pipeline via the ingest API.
